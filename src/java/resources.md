# Resources

This page collects the main Java resources we want new programmers to use.

Start with [Java](./README.md) if you want the beginner path first.

## Primary resources

- Codecademy Java course: <https://www.codecademy.com/learn/learn-java>
- Oracle Java tutorial: <https://docs.oracle.com/javase/tutorial/>

For the Oracle tutorial, focus on the first four chapters first.

## What to use each resource for

- Use Codecademy for guided practice and syntax repetition.
- Use the Oracle tutorial for clearer explanations of how Java is structured.
- Use team and FRC code after that to practice reading real programs.
