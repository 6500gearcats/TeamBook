# Java

This section is for students who need to learn or review Java before working on robot code.

You do NOT need to master all of Java before contributing, but understanding the basics will save you a lot of time.

## Recommended learning order

1. Complete the [Codecademy Java course](https://www.codecademy.com/learn/learn-java) sections your mentor assigns.
2. Read the first four chapters of the [Oracle Java tutorial](https://docs.oracle.com/javase/tutorial/).
3. Practice reading simple Java code from this team book and the robot codebase.
4. Move on to [FRC Code](../frc_code/README.md) once basic Java syntax feels familiar.

## What matters most for FRC

You do not need every Java feature right away.
The most useful early skills are:

- reading methods
- understanding classes and objects
- following control flow - `if` statement, `for` or `while` loop
- tracing values through code
