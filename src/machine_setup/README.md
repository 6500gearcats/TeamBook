# Setup

Use this page to get your computer ready for team programming work.

## What to install

### 1. Git

Install Git so you can clone repositories, create branches, and push changes.

- GitHub setup guide: <https://docs.github.com/en/get-started/quickstart/set-up-git>
- Git install guide: <https://git-scm.com/book/en/v2/Getting-Started-Installing-Git>
- You may need to request permission from a mentor to access the team GitHub organization.

### 2. WPILib

Install WPILib

The WPILib installer sets up the FRC development environment for Java teams, including the tools and dependencies needed for robot programming.
Choose to install the included vscode when prompted during the WPILib installation process.
- WPILib installation guide: <https://docs.wpilib.org/en/stable/docs/zero-to-robot/step-2/wpilib-setup.html>

### 3. VS Code

Most students use Visual Studio Code IDE.

For FRC programming, do not look for separate VS Code.
Install WPILib, and use the VS Code environment that comes with the WPILib setup process.

## Java

You usually do not need separate Java install.
The WPILib setup is the correct Java setup path.

## After setup

You should be able to:

- sign in to GitHub
- access the GearCats organization
- clone a team repository
- open the project in the WPILib VS Code environment

## If setup fails

- bring the exact error message
- ask in the programming team on chat or at the next meeting
