Terms:
- `FRC` stands for `FIRST Robotics Competition`.
- `WPILib` is the main library used to build and organize FRC robot programs.

Most teams, including ours, organize robot code around a few core ideas:

- `subsystems`: major robot parts such as the drivetrain, intake, or elevator
- `commands`: actions the robot should perform using those subsystems
- `robot container`: where buttons, commands, and subsystem wiring are connected together
