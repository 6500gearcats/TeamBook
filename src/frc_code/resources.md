# Resources

This page collects useful references for students learning FRC programming.

Start with [FRC Code](./README.md) if you want the beginner path first.

## Official documentation

- WPILib docs: <https://docs.wpilib.org/en/stable/>
- WPILib getting started: <https://docs.wpilib.org/en/stable/docs/getting-started/>
- Command-based programming: <https://docs.wpilib.org/en/stable/docs/software/commandbased/index.html>
- WPILib example projects: <https://docs.wpilib.org/en/stable/docs/software/examples-tutorials/wpilib-examples.html>
- Robot simulation: <https://docs.wpilib.org/en/stable/docs/software/wpilib-tools/robot-simulation/introduction.html>

## Video learning

- FRC 0 to Autonomous YouTube channel: <https://www.youtube.com/channel/UCmJAoN-yI6AJDv7JJ3372yg>

This channel is especially useful for students who learn better from walkthroughs than from documentation alone.

## Java background

- Java section of this book: [Java](../java/README.md)
- Java resources in this book: [Java Resources](../java/resources.md)

FRC programming is much easier if you are already comfortable with classes, methods, objects, and reading compiler errors.

## How to use these resources well

- Use WPILib docs for correctness and current structure.
- Use videos for intuition and step-by-step examples.
- Use team code to understand how our robot is actually organized.
- Ask a mentor or experienced student before making changes you do not fully understand.
