# Introduction
TeamBook is the starting point for GearCats students and mentors of the GearCats (FRC #6500). 

Use this page as the main table of contents for what to read next.

## What this book is for

This book is meant to help the team:

- learn core programming concepts
- understand how FRC code - `FIRST Robotics Competition`, is the robotics program our team competes in
- follow shared engineering process 
- find reference materials to learn

## When you get stuck

- Do NOT be afraid - jump in, break things!
  - the goal is to have fun and learn!
  - we are a team, ask for help
- Ask a mentor or experienced student a specific question
  - on the programming team on chat
  - at a build meeting
- Bring the code, error, or robot behavior you are seeing.
