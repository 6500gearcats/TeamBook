## What to practice

- open one team repository and look at the file list
- look at recent commits
- open a pull request and read the changed files
- compare two versions of a file

## What matters most at first

You do not need advanced Git right away.
The most useful early skills are:

- understanding commits
- recognizing branches
- reading pull requests
- asking for help before you are stuck in a merge problem

## Recommended order

1. Read GitHub Hello World.
2. Learn how to clone a repository.
3. Learn how to create a branch.
4. Learn how to open a pull request.
5. Learn how merging works.
